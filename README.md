# 공금식탁 · 업무추진비 지도

아파트 검색 앱처럼 전국에서는 지역별 공개 식비 합계, 확대하면 식당별 지출액을 탐색하는 웹앱입니다.

운영 웹앱: https://dongyuuun-beep.github.io/gov-meal-map/

## 현재 범위

- 정적 웹앱: 지도 확대/축소, 지역 → 식당 전환, 기간·기관·목적·상호 검색, 합계/인당 비용 전환, 상세 원문 링크, CSV 다운로드.
- 실자료: 서울시 본청 2023~2026년 공개 지출 이력 중 식음료 후보, 세종시의회 최근 공개 XLSX, 경기도 감사1과와 울산시장 공개 웹 표, 화성·용인·수원·평택 공식 게시판 최신 10개 게시글의 지원 첨부. 전국 전수조사나 전체 기관 지출 합계가 아닙니다.
- 화면 체험용 데이터는 선택 시에만 활성화되며 실제 기관·지출과 섞지 않습니다.
- 광역 단위 역사적 17개 지역의 출처 조사와 주요 중앙부처의 확인 경로: [출처 조사](docs/SOURCES.md).
- 매일 GitHub Actions는 공개 웹 표 수집·검증·앱 데이터 갱신 후 저장소에 커밋합니다. GitHub 저장소에 코드와 워크플로를 연결했습니다. 네 도시는 XLS/XLSX·HWPX와 지원되는 PDF 표를 읽으며, 일부 형식은 미지원인 부분 수집입니다. 전국 수집은 후속 과제입니다.

## 실행

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. 지도 타일은 OpenStreetMap을 이용하므로 인터넷 연결이 필요합니다. 지도 로딩 실패 시에도 목록과 검색은 이용할 수 있습니다.

```sh
python scripts/collect.py
python -m unittest discover -s tests
```

수집 환경에는 Python 3.12+, curl이 필요합니다. GitHub 호스팅 실행기에는 기본 제공됩니다.

## 해석 기준

‘간담회’는 회식 확정이 아닙니다. 원문 목적과 식음료 관련 후보 분류를 별도로 보관합니다. 공개 인원은 실제 참석 여부를 검증한 값이 아닙니다. 인당 비용은 인원이 양수로 공개된 지출만의 `금액 합계 / 기재 인원 합계`이며, 개별 인당 비용의 단순 평균을 사용하지 않습니다. 참석 인원 합계는 연인원입니다.

지도의 지역은 **사용 장소 지역**입니다. 지출 기관 소재지와 구별합니다. 정확한 지점이 확인되지 않은 지출은 위치 확인 대기 목록에 남고, 식당 핀에는 포함하지 않습니다. 위치가 확인된 식당을 합친 금액과 전체 수집 금액을 구별합니다. 좌표는 검증 출처와 정밀도를 기록합니다.

프로그램 코드는 MIT 라이선스이며, 원자료의 이용조건은 각 출처를 따릅니다. 원자료에 변경금지 조건이 붙은 경우 자동으로 재배포 가능하다고 간주하지 않습니다. 초기 앱은 출처 확인용 최소 사실만 표시하고 원문 전체를 저장소에 재배포하지 않습니다. 공개 서비스 확대 전에 출처별 데이터 이용조건을 검토합니다.

## 매일 운영

GitHub 수집은 매일 오전 10:00 KST에 실행하며, 검증 후 GitHub Pages를 자동 배포합니다. ChatGPT나 이 채팅이 실행 중일 필요는 없습니다. 기존 Sites 예약은 중지했으며 Sites URL은 별도 초기 미리보기입니다. 매일 수집과 기관별 공표주기는 다릅니다. 분기 공개·지연·정정 자료를 위해 최근 6개월 게시물을 다시 수집하는 방식으로 확대해야 합니다. 현재 구현은 위 수집군과 경기 4개 시청 최신 10게시글씩을 갱신하며 전국 자동 전수 수집으로 표현하지 않습니다. 실패 시 기존 데이터를 유지하고 작업을 실패 처리합니다.

GitHub Actions가 수집·검증·커밋·GitHub Pages 배포를 모두 담당합니다. GitHub Pages의 Source를 GitHub Actions로 설정했습니다. 일부 출처가 실패하면 해당 출처의 기존 자료를 유지하고 성공한 출처만 갱신하며, 전체 실패면 배포하지 않습니다. 실행 로그와 JSON의 source_status에서 누락·오류를 확인할 수 있습니다.

자세한 설계는 [데이터·지도 기준](docs/DESIGN.md)을 참고하세요.

## 서울·세종 보완

서울은 OA-22156 공개 시트의 집행일 내림차순 최신 6,000행을 읽습니다. 이 중 식음료 후보만 표시하므로 연간 전체 금액이 아닙니다. 세종은 시의회 최신 게시글 6개 중 업무추진비 XLSX의 모든 시트를 읽습니다. 시장·본청·정부세종청사 전체와 구별합니다. 미수집 지역도 지도에 회색 표지로 나타나며 0원으로 계산하지 않습니다. 주소·건물 좌표는 도로명·번지·도시가 일치하는 OSM 후보만 캐시하며 상세에 주소 기준 위치라고 표시합니다. 새 주소 검수는 별도 보완해야 합니다.

## 대량 핀과 집계 정정

공개 시트는 pageNo가 1 증가할 때 100행을 이동하지만 1,000행을 반환합니다. 최초 구현의 연속 페이지 조회에는 중복이 있었습니다. 이 버전은 10페이지씩 이동하고 문서 ID·원문 RONUM·집행일시·사용처·금액 복합 키로 중복을 제거한 이력으로 서울 자료를 전면 교체했습니다. 이전 버전의 건수·합계는 현재 집계와 직접 비교하면 안 됩니다.

지출 원문은 OA-22156, 좌표는 서울시 일반음식점 인허가 OA-16094의 주소를 대조합니다. 중부원점 TM EPSG:5174 좌표를 WGS84 위경도로 변환하며, 주소 불일치·멀리 떨어진 복수 후보·상호만 같은 체인점은 제외합니다. 인허가 좌표는 현재 영업 여부를 보증하지 않습니다. 1970-01-01 원문 기본 날짜는 일자 미확인으로 표시합니다.

전국 보기에서는 지역 합계, 확대하면 Canvas 기반 실제 좌표 점이 나타납니다. 점에 마우스를 올리거나 선택하면 사용처·금액·인당 비용을 확인합니다. 같은 좌표는 합산하며 임의로 점을 흩뿌리지 않습니다.

이력 원본은 data.full.json.gz, 브라우저용 중복 문자열 제거 자료는 data.map.json.gz, data.json은 호환용 최신 1,000건과 전체 자료 경로를 담습니다. 현대 브라우저는 전체 자료를 압축 해제해 사용하고, 미지원 브라우저는 표본 범위를 표시합니다. 매일 작업은 전체 이력을 보존하면서 최신 공개 행과 좌표 인덱스를 갱신합니다.

전체 이력 재구성:

```sh
pip install -r requirements-geodata.txt
python scripts/backfill_history.py
```

원문 캐시는 data/raw/bulk에 저장되며 Git에 포함하지 않습니다.

## 화성·용인·수원·평택

‘식당 소재 시/군’에서 네 도시를 선택하면 주소가 확인된 해당 도시의 지출을 보고 지도를 이동합니다. `?city=수원`과 같은 링크도 지원합니다. ‘사용 기관’에서 시청을 선택하면 주소 미확인 건까지 해당 시청의 수집 지출을 볼 수 있습니다. 두 필터는 서로 다른 기준이며 함께 선택하면 교집합입니다. 좌표가 확인되지 않은 내역은 목록에서 원문·금액·인당 비용을 확인할 수 있습니다.

매일 자동 수집에서 읽을 수 없는 첨부는 상태와 링크를 기록하고 보존합니다. 상세 출처와 한계는 [출처 조사](docs/SOURCES.md)의 경기 4개 시 항목을 참조하세요.

명시된 경기 4개 시 주소의 새 좌표는 매일 최대 40개 도로명 주소를 OpenStreetMap Nominatim과 대조합니다. 도시·도로명·건물번호·국가가 모두 일치하고 멀리 떨어진 복수 후보가 없을 때만 주소 기준 핀을 추가합니다. 주소가 없는 상호의 지점은 자동 추측하지 않습니다. 지오코더 장애 때도 지출 갱신은 유지합니다. 공개 서비스의 초당 1회 제한을 준수하며 주소 캐시도 저장소에 보존합니다.

GitHub 실행기별 공공기관 연결 시간 초과에 대비해, 경기 4개 시 출처 연결에 실패하면 새 macOS 실행기에서 한 번 더 수집합니다. 재시도도 실패한 출처는 기존 자료를 유지하고 실패 상태를 공개합니다.
