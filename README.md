# 공금식탁 · 업무추진비 지도

아파트 검색 앱처럼 전국에서는 지역별 공개 식비 합계, 확대하면 식당별 지출액을 탐색하는 웹앱입니다.

운영 웹앱: https://dongyuuun-beep.github.io/gov-meal-map/

## 현재 범위

- 정적 웹앱: 지도 확대/축소, 지역 → 식당 전환, 기간·기관·목적·상호 검색, 합계/인당 비용 전환, 상세 원문 링크, CSV 다운로드.
- 실자료: 서울시 본청 최신 6,000행 중 식음료 후보, 세종시의회 최근 공개 XLSX, 경기도 감사1과와 울산시장 공개 웹 표. 전국 전수조사나 전체 기관 지출 합계가 아닙니다.
- 화면 체험용 데이터는 선택 시에만 활성화되며 실제 기관·지출과 섞지 않습니다.
- 광역 단위 역사적 17개 지역의 출처 조사와 주요 중앙부처의 확인 경로: [출처 조사](docs/SOURCES.md).
- 월별 GitHub Actions는 공개 웹 표 수집·검증·앱 데이터 갱신 후 저장소에 커밋합니다. GitHub 저장소에 코드와 워크플로를 연결했습니다. PDF/HWP/XLSX 전국 수집은 후속 과제입니다.

## 실행

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. 지도 타일은 OpenStreetMap을 이용하므로 인터넷 연결이 필요합니다. 지도 로딩 실패 시에도 목록과 검색은 이용할 수 있습니다.

```sh
python scripts/collect.py
python -m unittest discover -s tests
```

수집 환경에는 Python 3.12+, curl이 필요합니다. GitHub 호스팅 실행기에는 기본 제공됩니다.

## 해석 기준

‘간담회’는 회식 확정이 아닙니다. 원문 목적과 식음료 관련 후보 분류를 별도로 보관합니다. 공개 인원은 실제 참석 여부를 검증한 값이 아닙니다. 인당 비용은 인원이 양수로 공개된 지출만의 `금액 합계 / 기재 인원 합계`이며, 개별 인당 비용의 단순 평균을 사용하지 않습니다. 참석 인원 합계는 연인원입니다.

지도의 지역은 **사용 장소 지역**입니다. 지출 기관 소재지와 구별합니다. 정확한 지점이 확인되지 않은 지출은 위치 확인 대기 목록에 남고, 식당 핀에는 포함하지 않습니다. 위치가 확인된 식당을 합친 금액과 전체 수집 금액을 구별합니다. 좌표는 검증 출처와 정밀도를 기록합니다.

프로그램 코드는 MIT 라이선스이며, 원자료의 이용조건은 각 출처를 따릅니다. 원자료에 변경금지 조건이 붙은 경우 자동으로 재배포 가능하다고 간주하지 않습니다. 초기 앱은 출처 확인용 최소 사실만 표시하고 원문 전체를 저장소에 재배포하지 않습니다. 공개 서비스 확대 전에 출처별 데이터 이용조건을 검토합니다.

## 월별 운영

GitHub 수집은 매월 15일 09:20 KST에 실행하며, 검증 후 GitHub Pages를 자동 배포합니다. ChatGPT나 이 채팅이 실행 중일 필요는 없습니다. 기존 Sites 예약은 중지했으며 Sites URL은 별도 초기 미리보기입니다. 월별 수집과 기관별 공표주기는 다릅니다. 분기 공개·지연·정정 자료를 위해 최근 6개월 게시물을 다시 수집하는 방식으로 확대해야 합니다. 현재 구현은 위 네 수집군을 갱신하며 전국 자동 전수 수집으로 표현하지 않습니다. 실패 시 기존 데이터를 유지하고 작업을 실패 처리합니다.

GitHub Actions가 수집·검증·커밋·GitHub Pages 배포를 모두 담당합니다. GitHub Pages의 Source를 GitHub Actions로 설정했습니다. 일부 출처가 실패하면 해당 출처의 기존 자료를 유지하고 성공한 출처만 갱신하며, 전체 실패면 배포하지 않습니다. 실행 로그와 JSON의 source_status에서 누락·오류를 확인할 수 있습니다.

자세한 설계는 [데이터·지도 기준](docs/DESIGN.md)을 참고하세요.

## 서울·세종 보완

서울은 OA-22156 공개 시트의 집행일 내림차순 최신 6,000행을 읽습니다. 이 중 식음료 후보만 표시하므로 연간 전체 금액이 아닙니다. 세종은 시의회 최신 게시글 6개 중 업무추진비 XLSX의 모든 시트를 읽습니다. 시장·본청·정부세종청사 전체와 구별합니다. 미수집 지역도 지도에 회색 표지로 나타나며 0원으로 계산하지 않습니다. 주소·건물 좌표는 도로명·번지·도시가 일치하는 OSM 후보만 캐시하며 상세에 주소 기준 위치라고 표시합니다. 새 주소 검수는 별도 보완해야 합니다.
