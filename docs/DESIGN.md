# 데이터·지도 기준

## 지도 동작

1. zoom 9 미만: 식당 소재 광역 지역별 금액 말풍선. 클릭하면 해당 지역으로 확대.
2. zoom 9 이상: 공식 주소 대조 좌표를 Canvas 점으로 표시합니다. 같은 좌표는 합산하며, 확대하거나 점을 선택하면 사용처와 금액을 확인합니다. zoom 16 이상이고 화면 주변 점이 40개 이하일 때만 이름·금액 라벨을 계속 표시합니다. 화면 밖 점은 지도 레이어에서 제거하며, 이동·확대 시 거래 재집계를 하지 않습니다.
3. 식당 클릭: 집행 건별 날짜, 기관, 부서, 목적, 공개 인원, 원화 금액, 1인당 비용과 원문.
4. 위치 미확인 건은 별도 목록. 좌표를 임의로 구청·시청 위치에 배치하지 않음.
5. 기관 필터와 사용지역 필터는 별개. 서울 소재 식당에서 중앙부처가 쓴 금액은 서울 사용액으로 집계.

## 저장 필드

| 필드 | 뜻 |
|---|---|
| id | 출처 URL + 원문 행 번호 기반 안정 키 |
| date | 집행일 ISO 날짜, 일자 미공개는 null |
| institution / department | 기관과 사용 부서, 불명확한 부서는 추정하지 않음 |
| budget_category | 원문 예산 과목, 미공개는 null |
| purpose | 집행 목적 원문 |
| category | 식사/간담회/회의/기타 후보. 회식은 원문 명시 때만 |
| merchant / address | 원문 상호 / 별도 확인한 주소 |
| amount_krw | 금액 정수 원. 천원 단위는 ×1000 |
| participants | 공개 기재 인원. 미상·‘등’만 있는 건은 null |
| participant_text | 원문 대상·인원 표현 |
| payment_method | 카드/현금 등 원문 |
| spending_region | 사용 장소 광역 지역. 확인 전에는 null |
| location | lat, lng, precision, evidence_url. 미검증은 null |
| source_url / source_row | 게시글 URL, 원문 행 번호 |
| collected_at | 수집 시각 UTC |
| source_license | 원자료 이용조건 관측값 |

중앙부처 조직개편과 지역 통합에 대비해 장기적으로 기관 ID, 원문 명칭, 유효기간, 상위 기관을 분리해야 합니다. 기존 광주·전남 자료를 현재 이름으로 덮어쓰지 않습니다.

## 금액과 인원

필터 결과 전체 금액과 ‘인당 계산 가능한 지출’ 금액은 다를 수 있습니다. 전체 인당 값은 인원 확인 건만 `sum(amount) / sum(participants)`로 계산하고 대상 건수를 표시합니다. 동일 인물의 반복 참석은 구별할 수 없으므로 고유 인원으로 표현하지 않습니다. 취소·환급 건은 후속 스키마에서 원거래 참조와 함께 처리합니다. 식사·다과·선물 복합 결제는 식비만 분리할 근거가 없으면 혼합 비용으로 둡니다.

## 수집 단계

출처 등록 → 게시글 목록 탐색 → 첨부파일/표 원문 해시 → 기관별 파서 → 단위 변환 → 품질검증 → 식음료 후보 → 주소/지점 확인 → 지도용 JSON → 매일 갱신 커밋.

HTML을 먼저, XLSX/CSV 다음, PDF/HWP는 마지막으로 확장합니다. OCR 결과는 검수 전 지도에 올리지 않습니다. 원문 행 키와 버전 해시를 분리해 수정본을 신규 지출로 이중 합산하지 않습니다. 원본 보관은 비공개 저장소/객체 저장소에 출처별 이용조건에 맞춰 운영합니다.

## 정보공개청구 초안

기간: YYYY-MM-DD~YYYY-MM-DD. 대상: 기관 본청 장·차관/단체장, 실·국·과별 기관운영·시책추진·부서운영 업무추진비 및 회의 관련 식음료 지출. 전자파일 CSV/XLSX 형태로 집행일시, 사용 부서·직위, 예산과목, 집행목적, 사용처 상호·지점·주소, 공개 가능한 사업자 식별정보, 집행 대상 설명, 기재 참석 인원, 결제금액·취소금액, 결제방법, 공개 가능한 증빙의 제공을 요청합니다. 개인 참석자 실명·연락처·카드번호는 제외하고 부분공개 요청합니다.

청구 제출은 사용자가 직접 진행합니다. 총액만 있는 결산 통계로 개별 식당 지출을 복원할 수 없습니다.

확대·이동 이벤트는 한 프레임에 한 번 처리합니다. 필터 변경 때만 지점·지역 집계를 만들고, 지도 조작은 그 결과에서 화면 주변 좌표만 골라 기존 점을 재사용합니다. 화면 밖 점을 숨겨도 합계·검색·CSV는 전체 필터 결과를 유지합니다.
