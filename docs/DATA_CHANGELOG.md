# 데이터 집계 정정

## 대량 좌표 버전

서울 공개 시트의 반환 행수(1,000)와 pageNo 이동 행수(100)가 달랐습니다. 최초 버전은 중첩된 페이지를 각각 다른 지출처럼 누적할 수 있었습니다. 이번 버전은 페이지 이동 간격을 10으로 수정하고, 문서 ID·원문 RONUM·집행일시·사용처·금액 복합 키로 중복을 제거한 전체 이력으로 서울 기존 자료를 전면 교체합니다. 진짜로 값이 같은 별도 원문 행은 보존합니다.

이전 버전에서 안내한 수집 건수·금액은 정정 대상입니다. 현재 버전은 출처 원문 전체 행수와 수집 고유 행수를 일치 검증한 후 식음료 후보를 선별합니다. 2023~2026년 이력과 최신 갱신을 구별하며, 기본값으로 보이는 1970-01-01은 날짜를 추정해 고치지 않고 미확인으로 처리합니다.

좌표는 공식 인허가 주소를 대조한 값이며, 불일치·복수 지점·원문 주소 불충분 건을 수치 목표를 위해 임의 배치하지 않습니다.
