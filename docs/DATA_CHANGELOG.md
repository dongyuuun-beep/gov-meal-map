서울 공개 시트의 반환 행수(1,000)와 pageNo 이동 행수(100)가 달랐습니다. 최초 버전은 중첩된 페이지를 각각 다른 지출처럼 누적할 수 있었습니다. 이번 버전은 페이지 이동 간격을 10으로 수정하고, 문서 ID·원문 RONUM·집행일시·사용처·금액 복합 키로 중복을 제거한 전체 이력으로 서울 기존 자료를 전면 교체합니다. 진짜로 값이 같은 별도 원문 행은 보존합니다.

이전 버전에서 안내한 수집 건수·금액은 정정 대상입니다. 현재 버전은 출처 원문 전체 행수와 수집 고유 행수를 일치 검증한 후 식음료 후보를 선별합니다. 2023~2026년 이력과 최신 갱신을 구별하며, 기본값으로 보이는 1970-01-01은 날짜를 추정해 고치지 않고 미확인으로 처리합니다.

좌표는 공식 인허가 주소를 대조한 값이며, 불일치·복수 지점·원문 주소 불충분 건을 수치 목표를 위해 임의 배치하지 않습니다.

## 2026-11-14 · 식당 상세와 금액 표시 클릭 수정

어정역 주변에서 금액 표시를 눌러도 상세가 열리지 않는 현상을 재현했습니다. 금액 툴팁을 클릭 가능한 버튼으로 변경하고 가까이 확대하면 식당명을 함께 표시하며 점의 클릭 허용 범위를 넓혔습니다. 최대 30개 금액 표시·Canvas 렌더링·화면 안 지점만 그리는 처리는 유지합니다. 식당 클릭 때 확대 수준을 14로 강제 변경하던 동작을 없애 상세를 열어도 지도 중심·확대 수준·크기를 유지합니다.

식당 업종·메뉴명·등록 가격·등록일·출처 조회일을 지출과 구분해 제공합니다. 목록의 한 건을 선택해도 같은 식당의 현재 필터 내 이력을 함께 보여주며, 같은 건물의 다른 식당은 별도로 선택합니다. 정보가 없는 식당도 지출과 원문을 볼 수 있습니다. 기존 지출 금액과 집계 자료는 이번 화면 변경에서 수정하지 않았습니다.

## 2026-11-14 · 식당 종류와 연속 클릭 확대 수정 (v13)

식당 종류 15개 필터를 추가하고 목록·상세·CSV에 분류와 근거를 표시합니다. 등록 업종·메뉴를 우선하며 상호로 추정한 분류를 표시하고 미분류를 보존합니다. 소고기와 돼지고기를 모두 제공하는 등 여러 분류에 해당할 수 있고, 실제 주문한 메뉴를 뜻하지 않습니다. 지출 금액·행 자체는 변경하지 않았습니다.
